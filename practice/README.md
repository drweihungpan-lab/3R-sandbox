# Session 1 practice

This folder is where you practise the Git workflow. Nothing here is graded.

1. Create a branch named `group-N/your-topic`, where `N` is your group number.
2. Add a line to [shared-notes.md](shared-notes.md) under your group's heading.
3. Commit with a descriptive message, push the branch and open a pull request.
4. Review a teammate's pull request with at least one specific comment.
5. When two groups edit the same line, you will get a merge conflict. Resolve it, then merge.

You cannot push to `main`. Every change reaches it through a reviewed pull request.
