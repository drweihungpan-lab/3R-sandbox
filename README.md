# 3R-sandbox

Welcome! This is the practice space for the course *Repeatability, Reproducibility, and Replicability*. Nothing here is graded; it is a safe place to try things out before you work on your own project.

**Start here:**

- **[Sandbox rules](RULES.md)**: read these before you check in.
- **[Session 0 check-in](https://github.com/drweihungpan-lab/3R-sandbox/issues/1)**: post your check-in comment here.
- **[Session 0 guide](https://github.com/drweihungpan-lab/3R-teaching/blob/main/docs/session-0.md)**: the setup steps, if you have not done them yet.

**Session 1 practice:** the [practice folder](practice/README.md) and the Session 1 rules in [RULES.md](RULES.md).

**Device example:** the [device example](device-example/README.md) shows one analysis growing up in seven stages, from a notebook to a containerised application. It is the dataset used across the course.
